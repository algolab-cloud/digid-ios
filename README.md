# digid iOS SDK

On-device identity verification for Tanzania: NIDA ID card and driving licence reading, face
match and liveness. The `Digid` product is a compiled framework; `DigidModels` adds the model
files to your app (or deliver them yourself and open them with `NidaKyc(modelDirectory:)`).

```swift
.package(url: "https://github.com/algolab-cloud/digid-ios.git", from: "0.1.5")
```

Documentation: https://digid.co.tz/docs/quick-start-ios. Proprietary: see LICENSE; production use
needs a digid licence key. Open-source components and their licences: THIRD_PARTY_NOTICES.md.
